Translating MS/MS Spectra into Diagnostic Queries and MassQL

Overview

SpectraToQueries extracts skeleton-specific diagnostic fragment (_frag) and neutral-loss (_nl) ion queries from annotated MS/MS spectral libraries and translates them into MassQL queries.

For each chemical class (SKELETON) with at least n_skel_min spectra, spectra_to_queries() executes five steps:

  1. Preprocessing and intensity-weighted m/z harmonization: MS2 intensities are normalized to 100%, peaks below intensity_min and non-positive neutral losses are removed, and m/z values across spectra are aligned to intensity-weighted consensus centroids within dalton + mz * ppm / 1e6.
  2. Unbinned centroid evaluation: Candidate fragment and neutral-loss centroids are matched directly against the unbinned spectra, enforcing physical feasibility (precursor_mz - nl > 0).
  3. Candidate ion selection (hitting set + mRMR): Exact duplicate hit profiles are collapsed. Ions with 100% recall on the target skeleton are pruned via a greedy hitting-set cover of false-positive spectra, and remaining slots up to ions_max are filled by forward conjunctive Matthews Correlation Coefficient (MCC) gain penalized by correlation on negative spectra.
  4. Branch-and-Bound combination search: When exploring multi-ion conjunctions up to ions_max, branches whose zero-false-positive MCC upper bound cannot reach the best MCC found so far for that skeleton are pruned.
  5. Parsimonious query selection & MassQL export: Among combinations tied for the highest MCC on a skeleton, the combination using the fewest ions is retained and formatted into both a minimal human-readable query (combined_ions) and a directly executable MassQL statement (massql).

Generating queries

Run spectra_to_queries() on a small subset of the bundled Monoterpene Indole Alkaloids Database (mia_spectra_df):

library(SpectraToQueries)

utils::data(mia_spectra_df, package = "SpectraToQueries")

keep <- mia_spectra_df$SKELETON %in%
  c("Corynanthean", "Iboga", "Aspidosperma")
queries <- spectra_to_queries(
  spectra = mia_spectra_df[keep, ],
  export = NULL,
  ions_max = 4L
)

knitr::kable(queries, digits = 4)
skeleton mcc combined_ions massql
Aspidosperma 0.6947 134.0951_frag & 199.1217_nl QUERY scaninfo(MS2DATA) WHERE MS2PROD=134.0951:TOLERANCEMZ=0.014023 AND MS2NL=199.1217:TOLERANCEMZ=0.01
Iboga 0.6896 121.091_frag & 224.1054_frag QUERY scaninfo(MS2DATA) WHERE MS2PROD=121.091:TOLERANCEMZ=0.013633 AND MS2PROD=224.1054:TOLERANCEMZ=0.016723
Corynanthean 0.5021 116.0562_frag & 143.0735_nl QUERY scaninfo(MS2DATA) WHERE MS2PROD=116.0562:TOLERANCEMZ=0.013482 AND MS2NL=143.0735:TOLERANCEMZ=0.01

On the full bundled dataset (spectra_to_queries()), pass spectra = NULL (raw skeletons) or spectra = "grouped" (grouped skeleton classes), or supply a path to an .mgf file containing a SKELETON metadata field.

Converting expressions to MassQL

to_massql() converts any ion expression (or list of ion vectors) into a MassQL query. Because MassQL ignores TOLERANCEMZ when TOLERANCEPPM is present on the same condition, to_massql() emits a single effective tolerance modifier per condition: :TOLERANCEMZ= (round(dalton + max(mz) * ppm / 1e6, 6) on MS2PROD, and static dalton on MS2NL) when dalton > 0, or :TOLERANCEPPM= when dalton == 0 and ppm > 0, plus optional :INTENSITYPERCENT= when intensity_min > 0. Disjunctive (|) clauses are expanded to disjunctive normal form and joined with ;.

to_massql(
  c(
    "144.0807_frag & 171.0935_nl",
    "168.0808_frag & (180.0809_frag | 241.095_nl)"
  ),
  dalton = 0.01,
  ppm = 30.0,
  intensity_min = 5.0
)
#> [1] "QUERY scaninfo(MS2DATA) WHERE MS2PROD=144.0807:TOLERANCEMZ=0.014322:INTENSITYPERCENT=5 AND MS2NL=171.0935:TOLERANCEMZ=0.01:INTENSITYPERCENT=5"                                                                                                                                                     
#> [2] "QUERY scaninfo(MS2DATA) WHERE MS2PROD=168.0808:TOLERANCEMZ=0.015042:INTENSITYPERCENT=5 AND MS2PROD=180.0809:TOLERANCEMZ=0.015402:INTENSITYPERCENT=5 ; QUERY scaninfo(MS2DATA) WHERE MS2PROD=168.0808:TOLERANCEMZ=0.015042:INTENSITYPERCENT=5 AND MS2NL=241.095:TOLERANCEMZ=0.01:INTENSITYPERCENT=5"

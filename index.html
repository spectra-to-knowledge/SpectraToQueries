SpectraToQueries

SpectraToQueries discovers diagnostic MS/MS fragment (_frag) and neutral-loss (_nl) ion combinations from annotated tandem mass spectrometry libraries and translates them into MassQL queries. Candidate queries for each chemical class are ranked by Matthews Correlation Coefficient (MCC), selecting the smallest ion combination tied at the highest score.

Requirements

  • R (>= 4.5.0) with MsBackendMgf and Spectra.
  • MS2 spectra with class metadata: an .mgf file, a Spectra object, or a compatible data.frame containing MS2 scans, precursorMz values, and a SKELETON metadata column (lowercase skeleton is accepted as a fallback). Skeleton classes with fewer than n_skel_min non-empty MS2 spectra are skipped.

Installation

SpectraToQueries is distributed via r-universe:

install.packages(
  "SpectraToQueries",
  repos = c(
    "https://spectra-to-knowledge.r-universe.dev",
    "https://cran.r-universe.dev",
    "https://bioc.r-universe.dev"
  )
)

Usage

Run on the bundled raw Monoterpene Indole Alkaloids Database (mia_spectra_df):

SpectraToQueries::spectra_to_queries(export = NULL)

Run on the bundled grouped skeleton dataset (mia_spectra_grouped_df):

SpectraToQueries::spectra_to_queries(spectra = "grouped", export = NULL)

Generate queries from your own .mgf library and save the TSV output:

SpectraToQueries::spectra_to_queries(
  spectra = "path/to/library.mgf",
  export = "results/queries.tsv"
)

Pass export = NULL to return the data.frame without writing a file to disk.

Parameters

SpectraToQueries::spectra_to_queries(
  spectra = NULL,
  export = "data/interim/queries.tsv",
  dalton = 0.01,
  decimals = 4L,
  intensity_min = 0.0,
  ions_max = 10L,
  n_skel_min = 5L,
  n_spec_min = 3L,
  ppm = 30.0,
  mcc_min = 0.0,
  precision_min = 0.0,
  recall_min = 0.0,
  zero_val = 0.0
)

Output, MassQL translation, and known behavior

spectra_to_queries() returns (and optionally exports as TSV) one row per qualifying skeleton class:

  • skeleton: chemical class identifier.
  • mcc: Matthews Correlation Coefficient on the input MS2 library.
  • combined_ions: minimal conjunctive/disjunctive combination of fragments (_frag) and neutral losses (_nl).
  • massql: executable MassQL query (QUERY scaninfo(MS2DATA) WHERE ...).

You can also convert ion expressions or vectors directly with to_massql():

SpectraToQueries::to_massql(
  "108.0804_frag & (241.095_nl | 144.0807_frag)",
  dalton = 0.01,
  ppm = 30.0
)

Notes on query semantics:

  • MassQL ignores TOLERANCEMZ when TOLERANCEPPM is present on the same condition. When dalton > 0, to_massql() emits a single :TOLERANCEMZ= modifier (round(dalton + max(mz) * ppm / 1e6, 6) on MS2PROD and static dalton on MS2NL). When dalton == 0 and ppm > 0, it emits :TOLERANCEPPM=.
  • Disjunctive clauses in combined_ions are expanded to disjunctive normal form and separated by " ; " in massql.
  • Peak matching evaluates binary peak presence after relative base-peak normalization (0 to 100) and intensity_min filtering; relative intensity ratios between fragments are not encoded in the queries.
  • + characters in SKELETON labels are replaced with . for internal grouping (a warning is emitted if distinct labels collide).

Example data

The package ships two MIADB datasets as portable data.frame objects (with mz and intensity list columns):

  • mia_spectra_df: 321 MS/MS spectra across 81 skeletons (24,255 peaks total).
  • mia_spectra_grouped_df: 321 MS/MS spectra across 53 grouped skeleton classes.
utils::data(mia_spectra_df, package = "SpectraToQueries")
utils::data(mia_spectra_grouped_df, package = "SpectraToQueries")

## 4. Structural changes

- **Moved validation into `R/input_checks.R`**: relocated
  `validate_stq_inputs()`, extracted `format_num_constraint()` and
  `check_tolerance_args()` (shared with `to_massql()`), and defined single
  sources of truth for `mz_tolerance()`, `nl_tolerance()`,
  `normalize_skeleton_labels()`, and `is_frag_ion()`.
- **Extracted `compute_consensus_peaks()` in `R/harmonize_mzs.R`**: shared by
  `harmonize_mzs()` and `refine_feature_mzs()`, removing the cloned
  `combinePeaksData()` pipeline.
- **Split `R/spectra_to_queries.R` (912L -> 354L)**:
  - `R/mcc.R`: pure MCC scoring (`calc_mcc_vec()`, removing `ifelse()`).
  - `R/spectra_io.R`: MGF/dataset loading and TSV export boundary
    (`load_input_spectra()`, `empty_query_table()`, `write_query_table()`).
  - `R/select_candidates.R`: candidate selection & mRMR
    (`select_hitting_set_ions()`, `select_forward_mrmr_ions()`,
    `select_mrmr_ions()`, `extract_candidate_ions()`).
  - `R/search_combinations.R`: Branch-and-Bound search (`prune_skeleton_bnb()`,
    `prune_combinations_bnb()`, `summarize_best_queries()`).
  - `R/spectra_to_queries.R`: extracted `normalize_and_filter_spectra()` and
    `extract_feature_matrix()`; removed conditional `qd`/`hits` coupling.
- **Decomposed `R/to_massql.R`**: extracted `sort_ion_clause()`,
  `drop_superset_clauses()`, `format_massql_tolerance()`,
  `format_massql_conjunction()`, `try_factor_single_or_clause()`, and
  `format_massql_single()`.
- **Indexed `R/query_hits.R`**: split `match_fragment_hits()` and
  `match_nl_hits()` with globally sorted `findInterval()` peak/loss lookups.
- **Added `tests/testthat/test-properties.R` and shared loaders in
  `tests/testthat/helper-spectra.R`**.

No speculative traits/classes or new runtime dependencies were introduced.

## 6. Findings handed off

1. **`F-NEW-01` (`dalton = 0, ppm = 0` throws
   `Malformed ion token(s): '0_nl'`)**: During golden-corpus capture on
   `mia_spectra_df` with `dalton = 0, ppm = 0`,
   `Spectra::PrecursorMzParam(filterPeaks = "abovePrecursor", tolerance = 0, ppm = 0)`
   retains peaks at or within `5e-5` Da of `precursorMz`, producing a `0`
   neutral-loss column that formats as `"0_nl"`, which `parse_query_ions()`
   rejects because `vals <= 0`. Logged for correctness review; behavior
   preserved during refactoring.
2. **Existing open scientific questions (`AUDIT.md` OQ3--OQ5, OQ7)**: `" ; "`
   multi-query separator vs `|||` (OQ3), `mrmr_redundancy_weight = 0.3`
   empirical constant (OQ4), `refine_feature_mzs()` `+ 1` centroid weighting
   (OQ5), candidate discovery vs evaluation normalization base when
   `intensity_min > 0` (OQ7).

## 7. Deliberately not changed

- **Public function default literals (`spectra_to_queries()`, `to_massql()`)**:
  Kept inline in function signatures so `roxygen2` `\usage{}` and static checks
  match user-facing documentation directly.
- **`BiocParallel` dependency**: Not added to `Imports` (kept `Imports` strictly
  at 4 packages); parallel backend remains controlled by the user's
  `BiocParallel::bpparam()`.
- **`R/create_dir.R` `# nolint` block**: Retained because the 89-character
  `@source` URL cannot be wrapped cleanly.
- **`R/spectra_df.R`**: Retained as a standalone file because
  `data-raw/generate_spectra_data.R` loads it via `source()`.

## 8. Residual debt and risk

- **Upstream `Spectra` preprocessing (~16% CPU)**: `preprocess_spectra()` and
  `harmonize_mzs()` remain bounded by upstream `Spectra::reduceSpectra()`,
  `Spectra::deisotopeSpectra()`, and `Spectra::combinePeaksData()` +
  `BiocParallel` worker registration (~1.7s--4.3s total on `miadb_raw`).
- **`prune_skeleton_bnb()` cyclomatic complexity (27)**: Retained as one nested
  Branch-and-Bound loop to avoid per-node function call overhead inside the
  search.
- **11 uncovered defensive guard lines (99.02% total coverage)**: Empty-input,
  `NA` `denom`, `raw_max_k` zero-length, and unreachable `length(clauses) == 0L`
  defensive guards in `R/mcc.R`, `R/query_hits.R`, `R/select_candidates.R`, and
  `R/to_massql.R`.

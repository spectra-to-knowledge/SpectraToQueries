## 1. Specification summary

- Input: MS2 spectra with a `SKELETON` class label. Positive class = one
  skeleton; negatives = all other MS2 spectra with a non-empty label.
- Match rule (fragment m/z `f`): a peak `x` with
  `|x - f| <= dalton + f * ppm / 1e6` (Da). Neutral loss `n` (Da), precursor m/z
  `p`: fragment target `p - n`, required `> 0`, same rule on `p - n`.
- Peak filter: relative intensity `100 * I / max(I) >= intensity_min`.
- Score: MCC = (TP·TN − FP·FN) / sqrt((TP+FP)(TP+FN)(TN+FP)(TN+FN)), 0 when the
  denominator is 0. Selected query per skeleton: max MCC rounded to `decimals`,
  then fewest ions, unrounded MCC, precision, fragment count.
- Glossary: *m/z* (fragment, Th); *neutral loss* (Da, `p - fragment m/z`);
  *feature* (one `_frag` or `_nl` column); *skeleton* (class label);
  *conjunction* (`&` of ion tokens); *hit* (ion matched in a spectrum).

## 6. Open questions

- **OQ1 (MS2NL tolerance).** The pipeline matches neutral loss `n` with
  `dalton + (p - n) * ppm / 1e6` on the fragment m/z; `to_massql()` emits
  `TOLERANCEMZ = dalton`; MassQL's `TOLERANCEPPM` is applied to `n` itself (its
  source carries a TODO acknowledging this). Queries with `_nl` can match fewer
  spectra than their reported MCC implies. Options: (a) evaluate NLs with
  `dalton` only (changes MCC values); (b) emit an upper bound
  `dalton + max_precursor * ppm / 1e6` (needs the library's maximum precursor); (c)
  keep and document (current). Recommendation: (a), so the reported MCC is
  reproducible by the emitted query.
- **OQ2 (`INTENSITYPERCENT` boundary).** MassQL keeps `> threshold`, the
  pipeline `>= intensity_min`. Differs only at exact equality. Recommendation:
  keep `>=` and document (current).
- **OQ3 (`" ; "` separator).** Not part of the MassQL grammar; GNPS batch
  workflows use `|||`. Only reachable from user-supplied disjunctive input.
  Recommendation: return one element per clause (list) or switch to `|||` after
  confirming the target runner.
- **OQ4 (`mrmr_redundancy_weight = 0.3`).** No derivation or citation found.
  Needs a domain decision or a sensitivity analysis.
- **OQ5 (centroid weights `max(0, I) + 1`).** The `+ 1` keeps zero-intensity
  peaks in the mean but biases centroids toward low-intensity peaks.
  Intensity-only weights would change reported m/z values.
- **OQ6 (`remove-old-artifacts.yml`).** Disabled manually on GitHub, no runs,
  and `permissions: read-all` cannot delete artifacts. Delete or grant
  `actions: write`.
- **OQ7 (normalization base).** Candidate discovery normalizes after precursor
  peak removal; evaluation normalizes to the raw base peak (often the
  precursor), matching MassQL `INTENSITYPERCENT`. With `intensity_min > 0`
  discovery and evaluation can disagree on which peaks pass.
- **OQ8 (labels).** `SKELETON` values are not trimmed (`" A"` ≠ `"A"`); `+` is
  rewritten to `.`. Intended?
